# TIL - 2025년 9월 17일

## Zustand에서 Store 파일에 초기화 액션이 필요한 이유

### 주요 필요성

1. 상태 일관성 보장
2. 메모리 누수 방지
3. 에러 복구 메커니즘
4. 개발 및 테스트 환경에서의 활용


## 느낀점

처음에는 초기화 액션이 단순히 상태를 비우는 역할이라고 생각했지만, 실제로는 애플리케이션의 안정성과 예측 가능성을 보장하는 핵심 메커니즘이었다. 특히 SPA에서는 페이지 새로고침 없이 상태가 계속 유지되기 때문에, 적절한 시점에 상태를 초기화하지 않으면 메모리 누수나 예상치 못한 버그가 발생할 수 있다는 것을 배웠다.
