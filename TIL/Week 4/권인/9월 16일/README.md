## API 명세에 맞게 Type을 TypeScript 파일로 구분하는 이유와 목적

### 주요 목적

1. 타입 안전성 보장
2. API 명세와의 완벽한 일치
3. 도메인별 타입 분리

## 느낀점

처음에는 단순히 타입을 정의하는 것이라고 생각했지만, 실제로는 API 명세와 프론트엔드 코드 사이의 계약서 역할을 하는 것을 깨달았다. 백엔드 개발자와의 협업에서 타입 정의를 공유함으로써 의사소통 오류를 크게 줄일 수 있었고, 런타임 에러를 컴파일 시점에 미리 잡을 수 있어 안정성 측면에서 장점이 있음을 알게 되었다.
