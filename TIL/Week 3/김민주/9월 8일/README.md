## 9/8 (월) - 개발 플랫폼 선택 및 3D 구현 방향 결정

### 오늘 한 일
React Native와 Kotlin 네이티브 개발의 장단점을 비교 분석하고, 코코의 숲 프로젝트의 기술 스택을 최종 결정했다.

### React Native vs Kotlin 비교 결과

**React Native 선택 이유:**
- 크로스 플랫폼 개발로 iOS/Android 동시 지원
- JavaScript 기반으로 팀 내 학습 곡선이 낮음
- 웹 개발 경험을 활용 가능
- 빠른 프로토타이핑과 개발 속도

**Kotlin 대비 트레이드오프:**
- 네이티브 성능 대비 약간의 성능 저하
- 3D 렌더링에서 제약사항 존재

### 3D 구현 방향 확정
Blender를 활용한 아이소메트릭 홈 화면 구현 계획:
- 10x10 좌표 기반의 격자 시스템
- 나무 심기와 물주기 인터랙션
- 아이소메트릭 뷰로 입체감 있는 UI 제공

### 배운 점
기술 스택 선택 시 팀의 역량과 프로젝트 요구사항 사이의 균형점을 찾는 것이 중요하다. React Native로도 충분히 매력적인 3D 요소를 구현할 수 있다는 확신을 얻었다.
