Spring vs Spring Boot

Boot는 Starter, AutoConfiguration 제공 → 생산성↑.

순수 Spring도 WAR/JAR 패키징 가능, Boot는 JAR 실행 용이.

Kotlin & Android

Kotlin은 자바 기반 언어, 프레임워크 아님.

모바일: Jetpack Compose, Coroutines, Hilt, Retrofit, Room 등.

백엔드: Kotlin/Java + Spring Boot (JPA/Querydsl, Security+JWT).

Flutter vs React Native

Flutter: Dart, 위젯 기반, 성능↑.

RN: JS/TS, 네이티브 브리지 활용, 생태계 크다.

Git

fetch = 원격 → 로컬로 가져오기.

merge = 브랜치 합치기.

pull = fetch + merge.
