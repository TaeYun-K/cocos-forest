배운 점/메모
- UI/UX 수정은 초기보다 시간이 배 이상 걸림 → 컴포넌트 단위화 필요
- 발표 자료는 단순 화면 캡처가 아니라 서비스 흐름을 스토리텔링으로 보여줘야 효과적임
- PPT는 “기능 나열”보다 “문제 → 해결 → 기대효과” 스토리텔링 구조가 효과적임

이슈/결정
- 숲 표현 디테일은 추가 논의 필요 (나무 종류, 성장 속도 등)
- 발표 시간 제약에 따라 데모보다는 화면 중심 설명으로 가닥
