### [Docker] Dockerfile을 이용한 나만의 이미지 만들기
날짜: 2025-09-05

카테고리: Docker, DevOps

1. 오늘 배운 내용
어제는 docker pull 명령어로 Docker Hub에 있는 기존 이미지를 사용하는 법을 배웠다. 오늘은 여기서 한 단계 더 나아가, **Dockerfile**이라는 설계도를 직접 작성하여 내 애플리케이션이 포함된 커스텀 이미지를 만드는 방법을 학습했다.

이를 통해 어떤 환경에서든 내 애플리케이션을 동일하게 실행할 수 있는 기반을 마련하는 것이 목표였다. 간단한 Node.js 애플리케이션을 예시로 이미지를 빌드하고 실행하는 전 과정을 실습했다.

2. Dockerfile이란 무엇인가?
Dockerfile은 Docker 이미지를 만들기 위한 설계도 또는 레시피가 담긴 텍스트 파일이다.

이 파일 안에는 베이스 이미지 선택, 파일 복사, 의존성 설치, 실행 명령어 지정 등 이미지를 생성하기 위해 필요한 모든 명령어가 순서대로 기록된다. docker build 명령어를 실행하면 Docker는 이 Dockerfile을 읽어 순차적으로 명령을 수행하며 최종 이미지를 만들어낸다.

3. 주요 Dockerfile 명령어
오늘 실습에서 사용한 핵심적인 명령어들은 다음과 같다.

FROM: 생성할 이미지의 바탕이 될 베이스 이미지를 지정한다. (예: FROM node:18)

WORKDIR: 컨테이너 내에서 명령어를 실행할 작업 디렉터리를 설정한다. 이 디렉터리가 없으면 자동으로 생성된다. (예: WORKDIR /app)

COPY: 호스트(내 컴퓨터)의 파일이나 디렉터리를 컨테이너 안으로 복사한다. (예: COPY . . -> 현재 디렉터리의 모든 것을 컨테이너의 작업 디렉터리로 복사)

RUN: 이미지 빌드 과정에서 스크립트나 명령어를 실행한다. 주로 애플리케이션 의존성 설치에 사용된다. (예: RUN npm install)

EXPOSE: 컨테이너가 실행될 때 개방할 포트를 지정한다. 실제 포트 매핑(-p 옵션)과는 별개로, 이 이미지가 어떤 포트를 사용할 것인지 명시하는 역할을 한다. (예: EXPOSE 3000)

CMD: 컨테이너가 시작될 때 실행할 기본 명령어를 설정한다. Dockerfile에서 한 번만 사용할 수 있다. (예: CMD ["node", "app.js"])

💡 RUN vs CMD

RUN: 이미지를 만들 때(build) 실행되는 명령어. 의존성 설치 등 환경 구축에 사용.

CMD: 이미지를 기반으로 컨테이너를 실행할 때(run) 실행되는 명령어. 애플리케이션 구동에 사용.
