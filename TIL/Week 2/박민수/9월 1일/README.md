# 컴퓨터 공학의 인프라 (1): 핵심 개념과 구성 요소

컴퓨터 공학에서 **인프라(Infrastructure)**는 모든 디지털 서비스와 기술이 구동될 수 있도록 하는 근본적인 뼈대입니다. 우리가 매일 사용하는 웹사이트, 모바일 애플리케이션, 클라우드 서비스 등은 모두 이 보이지 않는 인프라 위에서 동작합니다. 인프라는 크게 물리적인 하드웨어와 논리적인 소프트웨어 계층으로 나눌 수 있습니다.

### 1. 하드웨어 계층: 디지털 세상의 물리적 기반

하드웨어는 인프라의 가장 기초를 이루는 물리적인 장비들을 의미합니다.

- **컴퓨팅 (Compute):**
  - **서버 (Server):** 연산을 처리하고 애플리케이션을 실행하는 고성능 컴퓨터입니다. 중앙처리장치(CPU), 메모리(RAM)가 핵심 부품입니다.
  - 사용자의 요청을 처리하고, 데이터를 가공하며, 소프트웨어를 실행하는 두뇌 역할을 합니다.

- **스토리지 (Storage):**
  - **데이터 저장소:** 생성된 데이터와 파일을 영구적으로 보관하는 공간입니다.
  - HDD(하드 디스크 드라이브), SSD(솔리드 스테이트 드라이브)부터 대규모 데이터를 위한 NAS(Network Attached Storage), SAN(Storage Area Network)까지 다양한 기술이 활용됩니다.

- **네트워크 (Network):**
  - **데이터의 통로:** 컴퓨팅 자원과 스토리지, 그리고 외부 인터넷을 연결하는 통신망입니다.
  - 라우터, 스위치, 방화벽, 케이블 등의 물리적 장비와 TCP/IP와 같은 통신 프로토콜을 포함합니다. 네트워크 없이는 데이터 전송과 서비스 제공이 불가능합니다.

### 2. 소프트웨어 계층: 하드웨어를 제어하고 추상화하는 힘

소프트웨어는 물리적인 하드웨어를 효율적으로 사용하고 관리할 수 있도록 제어하는 역할을 합니다.

- **운영체제 (Operating System, OS):**
  - 하드웨어 자원(CPU, 메모리 등)을 관리하고, 응용 프로그램이 실행될 수 있는 환경을 제공합니다.
  - 대표적인 서버 OS로는 **Linux**와 **Windows Server**가 있습니다.

- **가상화 (Virtualization):**
  - 현대 인프라의 핵심 기술로, 하나의 물리적 하드웨어를 논리적으로 분할하여 여러 개의 **가상 머신(Virtual Machine, VM)**이 동시에 실행되도록 합니다.
  - 이를 통해 물리적 자원의 활용도를 극대화하고, 각 서버 환경을 독립적으로 격리하여 안정성을 높일 수 있습니다.

- **미들웨어 (Middleware):**
  - 운영체제와 응용 프로그램 사이에서 중개자 역할을 수행하는 소프트웨어입니다.
  - 데이터베이스 관리 시스템(DBMS), 웹 서버(Apache, Nginx) 등이 대표적인 예입니다.
