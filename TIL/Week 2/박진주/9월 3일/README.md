오늘 목표
- 페이지 개선 프롬프트 정리 반영. 명칭·UI 정책 업데이트.

수행
- 프롬프트 정리 반영(홈/탄소발자국/챌린지/랭킹/마이페이지 전면 수정안).
- 홈: 배경 제거, 중앙 ‘CO2’ 그라데이션 텍스트, 하단 날씨 요소(먹구름·비·번개)로 해수면 상승 시각화. 하단부엔 진행 중 챌린지 1줄 요약 검토.
- 탄소기록→‘탄소발자국’로 변경. 설명 텍스트 삭제, 정보(ℹ️) 모달 추가, 상단 누적 수치 삭제, 오늘/이번주 가로 막대 그래프(좌 적색→우 녹색 그라데이션), 달력/카테고리 탭, LLM 카드 상단 배치, 날짜 선택 시 상세 보기.
- 챌린지: 참여버튼 제거. 특정 카드(No Cab, No 배달음식) 진행률 바 삭제.
- 랭킹: 상세설명 삭제, 주간/월간 탭 제거, Top3 트로피 유지, 사용자 4등 이하일 때 앞·뒤 구간 강조, 등수 변동치 표기.
- 마이페이지: 이름 대신 닉네임(unique), 수정 모달(이름/전화 번호 비활성, 닉네임/이메일만 수정 + 닉네임 중복확인 + 이메일 인증 플로우), 업적 섹션 삭제, 중앙 하단 ‘회원탈퇴’, 개인정보보호 버튼 제거.

추가 프롬프트 준비

- 금융 연동/소비 분석: 기관 선택, 인증, 카테고리별 탄소 배출 원형 차트, LLM 팁 카드.
- 스마트워치 연동/위젯: 페어링, 권한, 위젯 정보 구성.
