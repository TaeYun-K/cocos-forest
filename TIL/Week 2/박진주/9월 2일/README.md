오늘 목표
- 와이어 프레임 합의 및 네비게이션 구조 고정.
- 페이지별 핵심 정보구조 도식화.

수행
- 와이어 프레임 회의: 오프닝, 로그인, 메인 화면 러프 스케치 공유(그림판).
- 네비게이션 탭 확정: 홈 / 탄소기록(→ ‘탄소발자국’ 예정) / 챌린지 / 랭킹 / 마이페이지.
- 온보딩 전략: 로딩 대체형 온보딩(3장 슬라이드 + 마지막 버튼로 홈/로그인 진입).
- 홈: 상단 스탯(오늘 배출량, n일째 생존), 중앙 캐릭터, 하단 네비.
- 탄소기록(대시보드→이름 변경 예정): 소비내역 + 탄소달력 중심, 리포트는 보조.
- 챌린지: 매일 리셋, 자동참여. 보상은 포인트 대신 해수면 레벨 변화로 표현.
- 랭킹: 코코 생존시간 기반.

산출물/링크
- 회의 러프 스케치 이미지(플립보드 사진)
- 텍스트 초안(각 화면 요소 목록)

배운 점/메모
- 온보딩을 로딩의 대체로 설계하면 초기 리텐션 메시지 전달에 유리.
- “보상 = 해수면 하강”은 친환경 목표와 직접 연결되어 이해가 쉬움.
