# Three.js (3js)

## 개요
- **개발사**: 오픈소스 (mrdoob, 커뮤니티 주도)
- **언어**: JavaScript
- **목적**: 웹 브라우저에서 3D 그래픽을 쉽게 구현할 수 있도록 도와주는 라이브러리
- **렌더링 방식**: WebGL 기반 → 브라우저에서 하드웨어 가속 3D 그래픽 지원

## 주요 특징
- **3D 씬(Scene), 카메라(Camera), 조명(Light)** 등을 간단히 구성 가능
- 다양한 **기하도형(Geometry)**과 **재질(Material)** 지원
- 애니메이션, 파티클, 그림자, 반사/굴절 효과 구현 가능
- GLTF, OBJ 등 **3D 모델 파일 로드** 지원
- VR/AR (WebXR) 지원

## 장점
- WebGL을 직접 다루지 않아도 손쉽게 3D 구현 가능
- 커뮤니티와 자료가 풍부함
- 다양한 예제와 공식 문서 제공

## 단점
- 복잡한 대규모 3D 프로젝트에는 성능 한계 존재
- 기본 제공 기능은 많지만, 전문 게임 엔진(Unity, Unreal)에 비해 한계가 있음

## 요약
- **Three.js**는 웹에서 3D 콘텐츠(게임, 시뮬레이션, 데이터 시각화 등)를 구현할 때 가장 널리 사용되는 JS 라이브러리
