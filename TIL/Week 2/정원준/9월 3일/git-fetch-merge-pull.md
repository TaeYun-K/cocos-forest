# Git Fetch, Git Merge, Git Pull

## 1. git fetch
- **역할**: 원격 저장소의 최신 커밋/브랜치 정보를 **로컬로 가져오기**  
- **특징**
  - 로컬 코드에는 영향을 주지 않음
  - 원격 브랜치 상태를 확인만 가능 (`origin/main` 등)
  - 안전하게 최신 상태 확인 후 merge/rebase 여부 결정 가능

---

## 2. git merge
- **역할**: 두 개의 브랜치를 합침  
- **특징**
  - 현재 체크아웃된 브랜치에 다른 브랜치의 변경사항을 병합
  - 새로운 **병합 커밋(merge commit)** 이 생성될 수 있음
  - 충돌(conflict) 발생 시 수동 해결 필요

---

## 3. git pull
- **역할**: `git fetch` + `git merge` 를 한 번에 실행  
- **특징**
  - 원격 저장소의 최신 커밋을 가져오고, 자동으로 현재 브랜치에 병합
  - 편리하지만 충돌이 발생하면 예상치 못한 상황이 생길 수 있음
  - `--rebase` 옵션과 함께 자주 사용됨 (`git pull --rebase`)

---

## 요약 비교

| 명령어       | 동작 설명                                     | 로컬 코드 변경 여부 |
|--------------|-----------------------------------------------|---------------------|
| **git fetch** | 원격의 최신 정보만 가져옴 (병합 없음)         | ❌ 없음              |
| **git merge** | 다른 브랜치를 현재 브랜치에 병합              | ⭕ 있음              |
| **git pull**  | `fetch` + `merge` (자동 병합)                 | ⭕ 있음              |
