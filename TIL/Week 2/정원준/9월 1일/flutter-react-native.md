# Flutter vs React Native

## Flutter
- **개발사**: Google
- **언어**: Dart
- **렌더링 방식**: 자체 렌더링 엔진 (Skia) 사용 → 플랫폼 위젯에 의존하지 않음
- **장점**
  - iOS/Android 동일한 UI 일관성
  - 풍부한 위젯 제공
  - 빠른 핫리로드(Hot Reload)
  - 높은 성능 (네이티브 수준)
- **단점**
  - 앱 크기가 상대적으로 큼
  - Dart 언어 러닝커브
  - 생태계(패키지/라이브러리)가 React Native보다 상대적으로 작음

---

## React Native
- **개발사**: Meta (Facebook)
- **언어**: JavaScript / TypeScript
- **렌더링 방식**: 네이티브 컴포넌트 브리징
- **장점**
  - JS/TS 기반 → 웹 개발자가 접근하기 쉬움
  - 생태계와 커뮤니티가 크고 활발함
  - 많은 라이브러리와 플러그인 활용 가능
- **단점**
  - 플랫폼별 UI 차이가 발생할 수 있음
  - 브리징 구조로 인해 성능이 Flutter보다 떨어질 수 있음
  - 복잡한 네이티브 기능은 추가 구현 필요

---

## 요약
- **Flutter**: 성능과 UI 일관성을 중시하는 경우 적합  
- **React Native**: 빠른 개발, JS 생태계를 활용하고 싶을 때 적합
