# TIL - 2024년 9월 2일

## 1. 프론트엔드 개발자의 화면설계(와이어프레임) 작업 시 확인 사항

### 기본 원칙
**사용자 경험(UX)과 개발 효율성**을 동시에 고려

### 1. 사용자 요구사항 분석
**확인 사항**:
- **타겟 사용자층** 파악 (연령대, 기술 숙련도, 사용 환경)
- **핵심 기능과 부가 기능** 구분
- **사용자 시나리오** 작성 (User Journey)
- **접근성 요구사항** 확인 (웹 접근성 가이드라인)

**작업 방법**:
- 사용자 페르소나(Persona) 정의
- 태스크 플로우(Task Flow) 작성
- 정보 아키텍처(IA) 설계

### 2. 반응형 디자인 고려사항
**확인 사항**:
- **브레이크포인트** 설정 (Mobile: 320px~, Tablet: 768px~, Desktop: 1024px~)
- **콘텐츠 우선순위** 결정 (Mobile First 접근)
- **터치 인터페이스** 고려 (최소 44px 터치 영역)

**작업 방법**:
- 모바일 → 태블릿 → 데스크톱 순으로 설계
- 그리드 시스템 활용 (12컬럼 또는 8컬럼)
- 플렉서블한 레이아웃 구조 설계

### 3. UI 컴포넌트 표준화
**확인 사항**:
- **디자인 시스템** 기반 컴포넌트 정의
- **일관성 있는 스타일** 가이드 (색상, 타이포그래피, 간격)
- **재사용 가능한 컴포넌트** 식별

**작업 방법**:
- Atomic Design 방법론 적용 (Atoms → Molecules → Organisms)
- 버튼, 폼, 카드 등 기본 컴포넌트 템플릿 생성
- 스타일 가이드 문서화

### 4. 기술적 제약사항 고려
**확인 사항**:
- **개발 프레임워크** 특성 (React, Vue, Angular 등)
- **성능 최적화** 요구사항 (로딩 속도, 번들 크기)
- **브라우저 호환성** 범위
- **API 구조**와 데이터 흐름

**작업 방법**:
- 컴포넌트 계층 구조 설계
- 상태 관리 방식 고려
- 라우팅 구조 설계
- 에러 핸들링 시나리오 포함

### 5. 콘텐츠 및 정보 구조
**확인 사항**:
- **정보 우선순위** 설정 (F-패턴, Z-패턴 고려)
- **콘텐츠 길이 변화** 대응 (다국어, 동적 콘텐츠)
- **검색 및 필터링** 기능 고려
- **빈 상태(Empty State)** 처리

**작업 방법**:
- 카드 소팅(Card Sorting) 활용
- 콘텐츠 인벤토리 작성
- 네비게이션 구조 설계

### 6. 인터랙션 및 피드백
**확인 사항**:
- **사용자 액션**에 대한 즉각적 피드백
- **로딩 상태** 표시 방안
- **에러 메시지** 및 안내 문구
- **애니메이션과 트랜지션** 계획

**작업 방법**:
- 마이크로 인터랙션 설계
- 프로그레스 인디케이터 정의
- 툴팁 및 도움말 위치 결정

### 7. 성능 및 최적화
**확인 사항**:
- **이미지 최적화** 전략 (WebP, 지연 로딩)
- **폰트 로딩** 최적화
- **CSS/JS 번들링** 고려사항
- **SEO 요구사항**

**작업 방법**:
- Critical Rendering Path 고려
- Above-the-fold 콘텐츠 우선 설계
- 메타데이터 구조 계획
