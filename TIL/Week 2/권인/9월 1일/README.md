# TIL - 2025년 9월 1일

## 1. Kotlin 언어 정리 및 모바일앱/워치앱 개발 구현 가능성

### Kotlin 언어 특징
- **JetBrains**에서 개발한 **JVM 기반** 프로그래밍 언어
- **Java와 100% 상호 호환**되며, 기존 Java 라이브러리와 프레임워크를 그대로 사용 가능
- **Null Safety** 기본 제공으로 NullPointerException 방지
- **간결한 문법**: 보일러플레이트 코드 최소화
- **함수형 프로그래밍** 지원 (고차 함수, 람다 표현식 등)

### 모바일앱 개발
- **Android 공식 개발 언어** (Google 2017년 공식 지원)
- **Kotlin Multiplatform Mobile (KMM)**: iOS와 Android 공통 비즈니스 로직 공유 가능
- **Jetpack Compose**: 선언적 UI 프레임워크로 네이티브 Android UI 개발
- **코루틴(Coroutines)**: 비동기 프로그래밍을 간단하고 효율적으로 처리

### 워치앱 개발 구현 가능성
- **Wear OS** 앱 개발 가능 (Google의 스마트워치 플랫폼)
- **Android 기반**이므로 Kotlin으로 네이티브 워치앱 개발 가능
- **제한사항**: 
  - 작은 화면 크기에 맞는 UI/UX 설계 필요
  - 배터리 최적화 고려 필수
  - 센서 데이터(심박수, 가속도계 등) 활용 가능

## 2. 앱 애니메이션: SVG vs Lottie 비교

### SVG (Scalable Vector Graphics)
**개념**: XML 기반의 2D 벡터 그래픽 포맷

**특징**:
- **벡터 기반**: 해상도 독립적, 확대/축소해도 품질 손실 없음
- **작은 파일 크기**: 단순한 그래픽에 적합
- **CSS/JavaScript 제어**: 웹에서 스타일링 및 애니메이션 가능
- **SEO 친화적**: 텍스트 검색 가능

**애니메이션 구현**:
- CSS `@keyframes` 또는 JavaScript로 애니메이션 제어
- 간단한 회전, 이동, 크기 변경 등에 적합

### Lottie
**개념**: After Effects에서 만든 애니메이션을 JSON 형태로 렌더링하는 라이브러리

**특징**:
- **복잡한 애니메이션**: After Effects의 고급 애니메이션 효과를 그대로 구현
- **크로스 플랫폼**: iOS, Android, Web, React Native 지원
- **경량화**: 기존 GIF나 동영상 대비 훨씬 작은 용량
- **동적 제어**: 런타임에서 색상, 텍스트, 속도 변경 가능

**애니메이션 구현**:
- After Effects에서 디자인 → Bodymovin 플러그인으로 JSON 내보내기
- 앱에서 Lottie 라이브러리로 JSON 파일 렌더링

### 주요 차이점 비교

| 항목 | SVG | Lottie |
|------|-----|---------|
| **복잡도** | 간단한 도형/아이콘 애니메이션 | 복잡한 모션 그래픽 |
| **파일 크기** | 매우 작음 | 중간 (JSON 기반) |
| **제작 도구** | 코드 또는 일러스트레이터 | After Effects 필수 |
| **성능** | 가벼움 | 복잡할수록 리소스 사용량 증가 |
| **호환성** | 웹 표준 지원 | 별도 라이브러리 필요 |
| **사용 사례** | 로딩 스피너, 아이콘 애니메이션 | 온보딩, 브랜드 애니메이션 |

### 결론
- **간단한 애니메이션**: SVG 사용 권장
- **복잡하고 정교한 애니메이션**: Lottie 사용 권장
- **프로젝트 요구사항과 팀의 디자인 역량**을 고려하여 선택
