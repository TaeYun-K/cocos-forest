## 9/5 (금) - 메인 게임 화면 기획 확정 및 기술적 구현 방안 설계

### 오늘 한 일

"코코의 숲" 메인 홈 화면의 게임 시스템을 구체화하고, Kotlin 기반 네이티브 Android 앱으로의 기술적 구현 방안을 확정했다.

### 코코의 숲 메인 화면 기획 확정

핵심 게임 플로우

- 소비 내역 → 탄소 발자국 → 챌린지 → 포인트 → 숲 성장으로 이어지는 선순환 구조 완성
- 사용자의 실제 금융 소비가 게임 내 숲 생태계에 직접적으로 영향을 미치는 시스템

### 메인 화면 구성 요소

1. 아이소메트릭 필드: 숲을 2D 아이소메트릭 뷰로 표현하여 입체감 있는 게임 경험 제공
2. 포인트 경제 시스템: 나무 심기, 물주기로 포인트 활용
3. 나무 상태 관리 (HP 시스템): 물주기와 탄소 절약 성공 시 HP 증가, 실패 시 감소 (건강→약간 시듦→심하게 시듦의 3단계 시각화)
4. 코코 캐릭터 상호작용: 왼쪽 상단 기본 위치, 이벤트 발생 시 말풍선으로 피드백

### 기술적 구현 방안

- 앱 개발 플랫폼: Kotlin (Android Native)
금융 API 연동의 보안성, 복잡한 아이소메트릭 렌더링 성능 최적화, 디바이스 센서 활용의 정확성을 고려한 선택
- 애니메이션 전략: 2D + Lottie
아이소메트릭 뷰는 정적 배경 + 동적 오브젝트 조합으로 구현

### 배운 점

- 실제 금융 데이터와 게임 요소를 연결하는 것이 단순한 게이미피케이션보다 훨씬 복잡한 설계를 요구한다는 것을 깨달음
- 아이소메트릭 뷰는 2D 기술로도 충분히 입체적이고 매력적인 시각적 경험을 제공할 수 있으며, HP 시스템을 통한 즉각적 피드백이 사용자 행동 변화에 미치는 영향을 고려한 게임 밸런싱이 중요함

### 해결해야 할 과제

- 나무 HP 밸런스 조정
- 아이소메트릭 좌표계에서의 터치 이벤트 처리
- 실시간 애니메이션 균형점 찾기
