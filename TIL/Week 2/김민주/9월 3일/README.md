### Readdy AI 프롬프트 작성

기존 와이어프레임을 개선하기 위한 페이지별 상세 프롬프트를 작성:

1. 홈 페이지: 코코 캐릭터 중심의 환경 상태 표시
2. 탄소발자국 페이지: 달력/카테고리 탭, AI 제안 카드 추가
3. 챌린지 페이지: 진행률 바 차별화, 참여 버튼 제거
4. 랭킹 페이지: 사용자 중심 랭킹 표시 개선
5. 마이페이지: 닉네임 시스템, 프로필 수정 모달 개선

### 와이어프레임 수정 사항

- 배경 요소 제거로 깔끔한 인터페이스
- CO2 텍스트에 그라데이션 효과 적용
- 환경 변화 시각화 (날씨 요소 → 해수면 상승)
- 탭 아이콘을 발자국 모양으로 변경
- 정보 아이콘(ℹ️) 추가로 사용자 가이드 강화

### 배운 점

- 컬러 팔레트는 단순히 예쁜 색상이 아니라 브랜드 메시지를 전달하는 중요한 도구
- AI 프롬프트 작성 시 구체적인 색상 코드와 기능 명세를 포함하면 더 정확한 결과 도출
- 와이어프레임 수정 과정에서 사용자 피드백을 미리 고려한 UX 개선 포인트 발견
