## 9/2 (화) - 애니메이션 기술 스택 비교 분석

### 오늘 한 일

코코 캐릭터와 환경 변화를 표현할 애니메이션 기술 스택을 비교 분석했다.

### 기술 옵션 분석

2D SVG + Lottie 애니메이션
장점:

- 파일 사이즈가 작아 모바일 최적화
- 로딩 속도 빠름, 배터리 소모 적음
- 벡터 기반으로 다양한 해상도 지원
- After Effects 워크플로우로 제작 용이

단점:

- 3D 효과 제한적
- 복잡한 인터랙션 구현 어려움

3D 애니메이션 (Blender + Three.js)
장점:

- 입체적이고 몰입감 있는 표현
- 360도 회전, 깊이감 있는 환경 변화
- 복잡한 사용자 인터랙션 가능

단점:

- 파일 크기 및 성능 이슈
- 개발 복잡도와 제작 비용 증가
- 모바일에서 배터리 소모 큰 폭 증가

Unity (모바일 앱 임베딩)
장점:

- 고품질 3D 게임 경험
- 풍부한 애니메이션 도구

단점:

- 앱 크기 급격히 증가
- 하이브리드 앱에서 통합 복잡

### 결정 사항

메인 앱: 2D SVG + Lottie 애니메이션 채택

- 일상적으로 자주 사용하는 기본 화면들은 가볍고 빠르게
- 코코의 감정 표현과 기본적인 환경 변화는 충분히 구현 가능

게임 모드: Three.js 활용 검토

- 별도 화면에서 더 몰입감 있는 3D 경험 제공
- Progressive Loading으로 필요시에만 로드

### 배운 점

- 기술 선택 시 사용자 경험과 성능의 균형점을 찾는 것이 중요
- 하나의 기술만 고집하지 않고 기능별로 최적의 기술 조합 활용 가능
