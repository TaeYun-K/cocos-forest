# 📚 TIL (Today I Learned)

매일 배운 내용을 기록하고 공유하기 위한 저장소입니다.  
작은 내용이라도 꾸준히 기록하면서 학습을 정리합니다.

---

## 🗂️ 작성 규칙

1. **날짜별 폴더 생성**
   - 오늘 배운 내용을 기록하기 전에, **오늘 날짜로 된 폴더를 생성**합니다.  
   - 예:  
     ```
     2025-09-02/
     ```
   - 해당 폴더 안에 배운 내용을 마크다운 파일(`.md`)로 작성합니다.  

2. **파일명 규칙**
   - 배운 주제에 맞는 파일명을 사용합니다.  
   - 예:  
     ```
     2025-09-02/git-fetch.md
     2025-09-02/spring-security-authentication.md
     ```

3. **작성 형식**
   - 간단한 제목과 함께 배운 점을 정리합니다.  
   - 예:
     ```markdown
     # Git fetch란?
     원격 저장소의 최신 내용을 가져오지만 merge는 하지 않는다.
     ```
