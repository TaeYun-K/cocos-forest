## 이미지 규격:
- 크기: 200x200px (권장)
- 포맷: PNG (투명 배경 권장)
- 해상도: 72dpi 이상

## 사용법:
각 은행 로고는 ProfileScreen.tsx의 bankList 배열에서 require()로 불러와 사용됩니다.

## 주의사항:
실제 서비스에서는 각 은행의 공식 로고를 사용해야 하며, 저작권 및 브랜드 가이드라인을 준수해야 합니다.
