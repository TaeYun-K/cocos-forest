# 안드로이드 에뮬레이터 카메라 설정 가이드

## 문제 상황
윈도우에서 안드로이드 에뮬레이터를 사용할 때 OCR 카메라 기능에서 오류가 발생하는 문제

## 해결 방안

### 1. 자동 에뮬레이터 감지 및 시뮬레이션 모드
- 앱이 자동으로 에뮬레이터 환경을 감지합니다
- 에뮬레이터에서는 실제 카메라 대신 시뮬레이션된 이미지를 사용합니다
- 개발 모드에서만 동작하며, 실제 디바이스에서는 정상적으로 카메라를 사용합니다

### 2. 에뮬레이터 카메라 설정 (선택사항)
만약 실제 카메라를 에뮬레이터에서 사용하고 싶다면:

#### AVD Manager에서 카메라 활성화
1. Android Studio > Tools > AVD Manager
2. 에뮬레이터 편집 (연필 아이콘)
3. Advanced Settings > Camera
4. Front Camera: Webcam0 또는 VirtualScene
5. Back Camera: Webcam0 또는 VirtualScene

#### 에뮬레이터 실행 시 카메라 옵션 추가
```bash
emulator -avd <AVD_NAME> -camera-front webcam0 -camera-back webcam0
```

### 3. 현재 구현된 해결책
- ✅ 에뮬레이터 환경 자동 감지
- ✅ 시뮬레이션 모드로 OCR 기능 동작
- ✅ 사용자에게 에뮬레이터 모드 안내
- ✅ 실제 디바이스에서는 정상 카메라 사용

### 4. 테스트 방법
1. 에뮬레이터에서 앱 실행
2. 챌린지 > 텀블러 인증 선택
3. "영수증 촬영하기" 클릭
4. 시뮬레이션 이미지 사용 선택
5. "텀블러 인증하기" 클릭하여 OCR 테스트

### 5. 실제 디바이스 테스트
실제 안드로이드 디바이스에서는:
- 정상적으로 카메라 권한 요청
- 실제 카메라로 영수증 촬영
- OCR 기능 정상 동작

## 주의사항
- 에뮬레이터 모드는 개발 모드(`__DEV__`)에서만 동작
- 실제 배포 시에는 에뮬레이터 감지 코드가 제거되어야 함
- 프로덕션 빌드에서는 항상 실제 카메라 기능 사용
